## 💫 About Me

I'm a web developer based in Tunis, Tunisia, building clean, responsive web applications with **React**, **TypeScript**, and **Supabase**. I enjoy turning an idea into a working product, from the interface and user experience to authentication, database-backed features, and deployment.

My projects range from interactive front-end apps, such as movie discovery, workspace booking, and study session scheduling, to a role-based IT asset management system with a PostgreSQL backend. I care about readable code, clear documentation, and testing the logic that matters.

I'm currently open to **freelance projects** and **junior web developer** roles.

## 🤝 How I Can Help

- Build responsive websites and web apps with React and TypeScript
- Add authentication, databases, and role-based access with Supabase
- Deploy projects to Vercel with a clean, documented repository
